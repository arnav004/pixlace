# PixlAce

PixlAce is a simple browser-based image resizing tool that lets you resize an image to:

- Exact width
- Exact height
- Exact file size (KB)

all at the same time.

I built this because I needed an image for a website that required a very specific image dimension and file size limit.

I searched online, tried multiple tools, and ran into the same problems repeatedly:

- Some tools changed the dimensions but ignored the size limit
- Some compressed the image but changed the resolution
- Some had both options locked behind a paywall

The one tool that actually worked required payment, and I didn't want to pay for something this basic.

So I built PixlAce.

The name comes from:

PixlAce = Ace the pixel.

A lightweight, no-nonsense utility that does exactly what it should.

---

## Features

- Resize image to exact dimensions
- Compress image to target KB size
- Drag and drop upload
- Works fully in browser
- No signup
- No watermark
- No image upload to servers
- Mobile responsive
